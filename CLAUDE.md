# DRW Retail Fusion — drwretailfusion.com

## Branching (required)
- All development happens on the `dev` branch. Commit and push to `dev` only.
- Never commit or push directly to `main`. `main` is the production branch that Hostinger deploys; it is updated only by merging `dev` when the owner asks.

## Stack
Next.js 15 (App Router) + Prisma + Stripe (Checkout, Tax, Invoicing). See README.md for setup, Stripe and Hostinger deployment.
- Catalog: `src/data/products.json` (generated by `npm run catalog`)
- Stripe fulfillment lives in the webhook (`src/app/api/webhooks/stripe`), not the success page.
- Check with `npm run typecheck` and `npm run build` before pushing.
